# الدوري مع السقيفة — دليل التشغيل

تطبيق توقّع نتائج المباريات. ملف واحد `index.html` يعمل بوضعين:

- **الوضع المحلي** (الحالي): يشتغل فوراً، والتوقعات محفوظة على جهازك فقط. مناسب للتجربة.
- **وضع المنافسة المشتركة**: بعد ربط Firebase — كل اللاعبين يتنافسون على ترتيب واحد لحظي.

---

## ✅ ما الذي يعمل الآن

- شاشة دخول بالاسم (بدون كلمة سر).
- توقّع نوع النتيجة (فوز/تعادل/خسارة) = **٢ نقطة**، والنتيجة الدقيقة = **٥ نقاط**.
- مضاعفة **×٢** لمباريات القمة 🔥، و**+١** للتوقّع المبكّر (قبل ٢٤ ساعة).
- إقفال التوقعات تلقائياً عند بداية المباراة.
- ترتيب مستقل لكل دوري + ترتيب عام.
- **لوحة إدارة** (زر ⚙️ أعلى اليمين): إضافة مباريات، إدخال النتائج، احتساب النقاط تلقائياً.
  - رمز الدخول الحالي: `1990` — **غيّره** في السطر ٤٠٩ من `index.html` (`ADMIN_CODE`).

---

## ▶️ التشغيل محلياً

استيراد Firebase يحتاج خادماً بسيطاً (لا يعمل بفتح الملف مباشرة). من داخل مجلد المشروع:

```bash
npx --yes serve -l 5599 .
```

ثم افتح: `http://localhost:5599`

> ملاحظة: يظهر بانر أزرق "الوضع المحلي" حتى تُكمل خطوات Firebase أدناه.

## 🔥 تفعيل المنافسة المشتركة (Firebase)

### ١) إنشاء المشروع
1. ادخل [console.firebase.google.com](https://console.firebase.google.com) → **Add project**.
2. بعد الإنشاء، اختر **Web** (`</>`)  لإضافة تطبيق ويب، وسمِّه أي اسم.
3. سينسخ لك كائن `firebaseConfig` — احتفظ به.

### ٢) تفعيل تسجيل الدخول المجهول
- **Build → Authentication → Get started → Sign-in method → Anonymous → Enable**.

### ٣) إنشاء قاعدة البيانات
- **Build → Firestore Database → Create database** → ابدأ بـ **Production mode** → اختر المنطقة.

### ٤) لصق المفاتيح في التطبيق
افتح `index.html` وابحث عن الكتلة قرب السطر ٤٠٠، واستبدل قيم `PASTE_...` بقيم مشروعك:

```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "your-app.firebaseapp.com",
  projectId: "your-app",
  storageBucket: "your-app.appspot.com",
  messagingSenderId: "123...",
  appId: "1:123...:web:abc..."
};
```

بمجرد وضع مفاتيح حقيقية، يتحول التطبيق تلقائياً لوضع المنافسة المشتركة ويختفي البانر الأزرق.

### ٥) قواعد الأمان (Firestore Rules)
من **Firestore → Rules**، الصق التالي (مناسب لدوري بين الأصدقاء):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // الجميع (بعد الدخول المجهول) يقرأون كل شيء
    match /{document=**} { allow read: if request.auth != null; }

    // كل لاعب يعدّل بياناته وتوقعاته فقط
    match /players/{uid}      { allow write: if request.auth.uid == uid; }
    match /predictions/{pid}  { allow write: if request.auth.uid == pid.split('__')[0]; }

    // المباريات والنتائج: يكتبها أي مستخدم مسجّل (محمية عملياً برمز لوحة الإدارة)
    match /fixtures/{id}      { allow write: if request.auth != null; }
  }
}
```

> ملاحظة أمان: رمز لوحة الإدارة يحمي الواجهة فقط. لأمان أقوى للمباريات لاحقاً، نضيف قائمة مشرفين في قاعدة البيانات ونقيّد الكتابة عليهم.

### ٦) أول تشغيل بعد الربط
- ادخل بلوحة الإدارة ⚙️ → **تعبئة مباريات تجريبية** (أو أضف مبارياتك يدوياً).
- عند انتهاء أي مباراة: أدخل نتيجتها من اللوحة → تُحتسب نقاط الجميع تلقائياً.

## 🌐 النشر على GitHub Pages (لاحقاً)

1. أنشئ مستودعاً على GitHub وارفع محتوى المجلد.
2. **Settings → Pages → Branch: main / root → Save**.
3. سيعطيك رابطاً عاماً يشتغل مباشرة (بما أنه ملف HTML واحد).

> بما أن `apiKey` الخاص بـ Firebase للويب عام بطبيعته، لا مانع من رفعه. الحماية تكون عبر قواعد Firestore أعلاه.
